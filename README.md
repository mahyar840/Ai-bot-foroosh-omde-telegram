# کارمند — ربات فروش و پشتیبانی تلگرامی (فاز ۱)

## چطور کار می‌کنه (خلاصه)
1. تو خودت پست‌های منتخب تامین‌کننده رو **دستی فوروارد می‌کنی** به یک کانال/گروه خصوصی واسط (Middleman).
2. ربات که ادمین همون کانال واسطه، پست رو می‌بینه، قیمت رو استخراج می‌کنه، عکس رو با Groq چک می‌کنه که واترمارک/برند رقیب نداشته باشه، قیمت فروش رو با فرمول پلکانی حساب و رند می‌کنه، کپشن رو بازنویسی می‌کنه، لوگوتو رو عکس می‌ذاره، و نتیجه رو برات می‌فرسته تو پیوی با دکمه تایید/رد.
3. با تاییدت، پست تو کانال اصلی منتشر می‌شه.
4. اگه مشتری تو پیوی به ربات پیام بده، اسم/شهر/محصول موردنظرشو می‌پرسه، بهش شماره و آیدی تو رو می‌ده، و خلاصه‌ی درخواست + اطلاعات تماسش رو برات می‌فرسته.

## روش دیپلوی بدون سیستم شخصی (فقط با مرورگر)

کلودفلر می‌تونه مستقیم از روی یه ریپوی گیت‌هاب، خودش build و deploy کنه (سرویس‌ش اسمش **Workers Builds**‌ ست) — یعنی نه npm لازمه نه wrangler رو سیستم خودت، همه‌ش رو سرورهای خودشونه.

### قدم ۱ — کد رو بذار تو گیت‌هاب
1. تو github.com یه اکانت بساز (اگه نداری) و یه ریپوی جدید خصوصی بساز، مثلاً به اسم `karmand-resale-bot`.
2. از همون صفحه‌ی ریپو، گزینه‌ی "uploading an existing file" رو بزن و تمام فایل‌های داخل زیپی که برات فرستادم رو (با همون ساختار پوشه‌ای `src/`) بکش و ول کن (drag & drop). گیت‌هاب خودش پوشه‌بندی رو از روی مسیر فایل حفظ می‌کنه.
3. Commit کن.

### قدم ۲ — تو کلودفلر، ریپو رو وصل کن
1. تو داشبورد کلودفلر برو Workers & Pages → Create → **Import a repository**.
2. اکانت گیت‌هابتو وصل کن و ریپوی `karmand-resale-bot` رو انتخاب کن.
3. کلودفلر خودش `wrangler.toml` رو تشخیص می‌ده و build/deploy رو خودکار انجام می‌ده (نصب پکیج‌ها + دیپلوی، همه رو خودشون).

### قدم ۳ — KV namespace بساز (از داشبورد، بدون CLI)
1. Workers & Pages → KV → Create a namespace → اسمش بذار `BOT_KV`.
2. برو تو تنظیمات Workerت (Settings → Bindings) و یه KV binding جدید اضافه کن: اسم متغیر `BOT_KV`، و namespace‌ای که ساختی رو انتخاب کن.

### قدم ۴ — متغیرها و رمزها رو از داشبورد ست کن (بدون CLI)
تو تنظیمات Worker → **Settings → Variables and Secrets**:
- به‌عنوان **Secret** اضافه کن: `BOT_TOKEN`، `GROQ_API_KEY`، `WEBHOOK_SECRET` (یه رشته رندوم دلخواه بساز، مثلاً چندتا حرف و عدد قاطی).
- به‌عنوان متغیر معمولی (Plaintext) این‌ها رو هم ست کن یا از همون `wrangler.toml` که تو ریپو گذاشتی استفاده کن: `OWNER_CHAT_ID`، `MIDDLEMAN_CHAT_ID`، `TARGET_CHANNEL_ID`، `OWNER_PHONE`، `OWNER_TELEGRAM_USERNAME`، `LOGO_URL`.
- آیدی عددی تلگرام خودتو از ربات @userinfobot بگیر.
- بعد از تغییر متغیرها، یه بار از داشبورد "Retry deployment" یا "Deploy" بزن تا اعمال بشه.

### قدم ۵ — Webhook تلگرام رو وصل کن (فقط با مرورگر)
بعد از دیپلوی، آدرس Workerت یه چیزی شبیه این می‌شه:
`https://karmand-resale-bot.YOUR_SUBDOMAIN.workers.dev`

فقط این آدرس رو (با مقادیر واقعی خودت جای BOT_TOKEN و بقیه) تو مرورگر باز کن — همین کافیه، نیازی به ترمینال نیست:
```
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://karmand-resale-bot.YOUR_SUBDOMAIN.workers.dev&secret_token=<WEBHOOK_SECRET>
```
اگه جواب `{"ok":true,...}` گرفتی، وصل شده.

### قدم ۶ — تست کن
یه پست نمونه (عکس + کپشن با قیمت) رو تو کانال واسط فوروارد کن، باید تو پیوی ربات پیش‌نمایش با دکمه تایید/رد بگیری.

## نکات مهم
- مدل‌های Groq که الان (آگوست ۲۰۲۶) فعالن و تو کد گذاشتم: `openai/gpt-oss-120b` برای متن، `qwen/qwen3.6-27b` برای ویژن. مدل ویژن فعلاً preview هست، یعنی Groq ممکنه بدون اطلاع قبلی جایگزینش کنه — اگه یه‌وقت خطای "model not found" گرفتی، از https://console.groq.com/docs/models چک کن و مقدار `GROQ_VISION_MODEL` رو تو داشبورد کلودفلر عوض کن.
- `extractPriceFromCaption` در `src/pricing.ts` فرمت‌های رایج قیمت رو پوشش می‌ده ولی صد در صد نیست — پست‌هایی که قیمتشون پیدا نشه بهت اطلاع داده می‌شه.
- پله‌های سود در `DEFAULT_TIERS` (`src/pricing.ts`) هستن؛ برای تغییرشون باید یه ادیت کوچیک تو فایل بزنی و push کنی (از همون گیت‌هاب هم می‌تونی ادیت کنی، بدون سیستم شخصی).
- این کد رو من نتونستم روی یه اکانت واقعی تست کنم (اینجا دسترسی شبکه ندارم) — منطقش درسته ولی موقع تست اول ممکنه یه دیباگ کوچیک لازم بشه.

## فاز ۲ (بعداً)
جمع‌آوری خودکار از کانال‌های تامین‌کننده (بدون فوروارد دستی) نیاز به یه اتصال userbot/MTProto جدا داره چون با ماهیت Workers جور درنمیاد — بعداً جدا طراحیش می‌کنیم.
